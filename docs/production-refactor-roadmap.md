# Production Refactor Roadmap

## Objective

Migrate the existing application to the architecture defined in
`nextjs-redux-toolkit-production-architecture.md` without changing visible
behavior or removing the mock-data fallback required by frontend-only flows.

## Baseline audit (2026-11-24)

- 407 tracked files
- 337 tracked TypeScript/JavaScript/CSS files
- Approximately 78,000 code lines
- 167 application routes generated by the production build
- More than 20 source files exceed 1,000 lines
- Redux previously used a module-level singleton store
- Reducers previously performed browser-storage side effects
- The primary RTK Query API contains approximately 80 endpoints
- Public, admin, teacher, parent, and student screens frequently depend on a
  single bootstrap mock database response

## Non-negotiable migration constraints

1. Preserve current routes, visual output, and user workflows.
2. Preserve mock responses for endpoints without a working backend.
3. Keep real API behavior for endpoints already connected to the backend.
4. Keep every intermediate change type-safe and production-buildable.
5. Do not combine visual redesign with architectural extraction.
6. Move code in vertical slices so each phase can be verified independently.

## Completed foundation

- [x] Replace the module-level Redux singleton with `makeStore()`.
- [x] Add a request-safe Client Component `StoreProvider`.
- [x] Add a dedicated root reducer composition module.
- [x] Keep typed hooks independent of the barrel module.
- [x] Move `localStorage` effects out of reducers and into listener middleware.
- [x] Verify the production build across all 167 routes.

## Verification policy

Every migration slice must pass:

1. `npm run lint` (TypeScript validation: `tsc --noEmit`)
2. `npm test` (Unit test runner via `tsx --test tests/**/*.test.ts`)
3. `npm run build` (`next build --webpack`)
4. Route smoke checks for all 167 application routes
5. Mock-mode and real-API-mode boundary checks when the feature supports both

The roadmap is updated as each vertical slice is completed.
